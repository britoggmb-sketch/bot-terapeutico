# 🌿 Assistente de Escuta Ativa e Reflexão Psicológica

Assistente virtual integrado ao Telegram capaz de processar mensagens de texto e áudios de voz gravados pelo microfone, atuando como um espaço seguro de escuta ativa e autorreflexão com fundamentação na literatura da psicologia (TCC, Humanismo e Logoterapia).

---

## 🚀 Funcionalidades
- **Escuta Multimodal:** Recebe e analisa tanto mensagens de texto quanto notas de voz (`.ogg`) gravadas no celular.
- **Abordagem Reflexiva:** Identifica padrões de pensamento e crenças nucleares sem fornecer diagnósticos clínicos fechados.
- **Perguntas Socráticas:** Conclui as interações estimulando a reflexão autônoma.
- **Disponibilidade 24/7:** Hospedado em nuvem com monitoramento contínuo de uptime.

---

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** Python 3
- **Interface:** API de Bots do Telegram (`pyTelegramBotAPI`)
- **Inteligência Artificial:** Google Gemini API (Processamento nativo de texto e áudio)
- **Hospedagem:** Render Cloud Services
- **Monitoramento:** UptimeRobot (Prevenção de hibernação)
